HOW TO READ THIS

A review queue.
With the working shown.

A changed results page is a reason to look closer. It does not prove why rankings changed or tell you to rewrite everything.

  1. Hold the context still.

    The default baseline uses three eligible captures. Country, language, location, device, and rule version must match.

  2. Separate the signals.

    Intent 35%, URL turnover 25%, result types 20%, rank movement 10%, and feature changes 10%. This is a prioritization score, not a probability.

  3. Require repeated evidence.

    The default alert needs two spaced captures. English and Finnish lexical rules infer intent; ambiguous results remain unknown. A page match uses a declared profile, a local export, or an optional public-page fetch.

  4. Keep a human in the loop.

    Review current pages, classification evidence, and collection health. AI Overview presence is observed separately; no citation benchmark or click-impact claim is implied.
